# 🔴 Crimson Client

**Official repository for Crimson Client and its companion components.**

Crimson Client is a Minecraft client for Minecraft 1.21.11.

## 📦 Crimson Extra Component

Crimson includes an additional Windows component called **Crimson Extra**.

- **Version:** 1.0.0
- **Platform:** Windows 10/11, 64-bit
- **Executable:** `Crimson.exe`
- **Distribution:** GitHub Releases

[**Download Crimson Extra v1.0.0**](https://github.com/NikoFemboy/Crimson/releases/tag/v1.0.0)

The component is distributed separately and is used as part of Crimson Client's startup and functionality.
